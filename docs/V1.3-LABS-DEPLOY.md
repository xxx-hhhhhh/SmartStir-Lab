# SmartStir Lab V1.3.1 Preview — 多用户 / 多实验室 / 多 ESP32 开发版

> 开发分支：`feature/labs-users-i18n-v1.3`。现网 V1.2.0 Railway Function 和公开 APK **没有被替换**。

## 功能

- 用户名 + 密码注册 / 登录；密码用每用户独立随机盐与 scrypt 存为摘要。
- 已注册用户创建实验室、查看加入的实验室、接受/拒绝邀请。
- 创建者通过用户名邀请已注册用户，受邀用户确认后才能加入。
- 实验室创建者添加 ESP32；设备绑定需要它在 MQTT 中发布的**实时配对证明**，防止仅凭设备编号夺取他人设备。
- 每个用户只能查询/控制自己所属实验室的设备；只有创建者可以邀请、绑定。
- 每台设备使用独立设备编号、独立 MQTT 身份和独立随机配对码。
- APP 支持简体中文、English、日本語，设置保存在手机本地。
- 设置内「启动前二次确认」默认关闭。仅取消 APP 确认弹窗，不关闭 ESP32 断网停机和 180 秒保护；GPIO32 仍不使用。

## ESP32 配对及多设备

每一台 ESP32 都需要单独配置未公开的本地 `firmware/SmartStir/secrets.h`：

```cpp
#define SMARTSTIR_DEVICE_ID "stirrer-002"
#define SMARTSTIR_PAIRING_CODE "32_CHAR_RANDOM_STRING_LOCAL_ONLY"
```

在 Windows PowerShell 用下面的命令生成每台设备各自的 32 位随机代码：

```powershell
[guid]::NewGuid().ToString("N")
```

请在私有 `secrets.h` 中替换 `SMARTSTIR_PAIRING_CODE`，代码不要提交到公共仓库。EMQX 后台也要为每台 ESP32 创建独立 MQTT 登录账户与相应主题权限。烧录后串口（115200）会打印设备 ID 和配对码，并通过 TLS MQTT 定时上报配对信息。APP 的实验室创建者进入「添加 ESP32」，输入设备 ID、配对码和显示名称，网关仅在收到近 5 分钟内的配对证据时允许绑定。旧固件不广播配对证明，但迁移后的旧 `stirrer-001` 会保留在原管理员的默认实验室。

## 关于「保护」开关

旧版控制页每次 START 都弹现场确认框。V1.3 把这个**APP 交互确认**改成设置项，默认为关闭；设置里可开启。软件里的 180 秒、断网自动停止、断电保护提醒不是此设置能关闭的功能。云端发 STOP 并不能取代现场独立断电开关。
