## 关键局限

- `v1.3.3` 虽然发布为 stable，但仍是开发用 Debug 签名 APK，**未完成全部 ESP32 硬件端到端验收**。
- **已核验：v1.2 与 v1.3.3 的 Android V2 签名证书 SHA-256 不同，不能直接覆盖安装。** 此结果来自 GitHub Actions 下载并校验两份 APK 后，使用 Android `apksigner verify --print-certs` 检查。

- GitHub Release 的标记可变，但已经安装的 APK 不会被远程自动降级。
- 云端 Railway V1.3 服务和 PostgreSQL 是独立系统；修改 GitHub Release **不会**回滚 Railway 数据库或网关。

## 回退步骤（仅在用户要求时执行）

1. **撤回 GitHub 正式更新入口（保留文件与哈希）**：`gh release edit v1.3.3 --prerelease --repo xxx-hhhhhh/SmartStir-Lab`，之后验证 `GET /releases/latest` 是否恢复到 `v1.2.0`。不需删除代码或 APK。
2. 如果仅需停止用户从 V1.2 检测到升级，执行第 1 步即可，不涉及 Railway、EMQX、设备或数据库变更。
3. 需要 APP 降级时：先备份本地设置，再按 Android 签名约束安装适用的旧版本；注意 Android 不支持任意原位降级。
4. **云端回退需单独处理**：先保存数据库备份，确认迁移兼容，使用历史云端代码版本重新部署，而不是盲目删除 PostgreSQL 表。
5. 回退后分别验证 GitHub `releases/latest`、Railway `/health`、MQTT 订阅日志与必要的设备权限。
